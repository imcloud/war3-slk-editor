# War3 SLK Editor

在 VS Code 中像电子表格一样查看和编辑 Warcraft III 的 `.slk` 文件。

## 功能

- 表格化显示 `.slk`，支持虚拟滚动，大文件也不卡
- 单击选中，双击编辑
- 支持行/列的插入、删除、追加、复制
- 支持 Ctrl+C / Ctrl+V / Ctrl+X，可粘贴 Excel 多格数据
- 右键菜单：复制 / 剪切 / 粘贴 / 清空
- 顶部关键词实时过滤
- 列可折叠

## 使用

1. 在 VS Code 中打开任意 `.slk` 文件（如 `units/itemdata.slk`）
2. 扩展会自动以表格形式打开
3. 编辑后按 `Ctrl+S` 保存

## ⚠️ 重要提示：SLK 语义可能丢失

**SLK 格式没有统一规范，不同工具产出的文件存在大量变体。**本扩展在编辑和保存时会重新生成文本输出，尽管已尽可能保留原始格式（`F` 记录、`B` 记录、`P`/`O` 记录、换行符、引号等），但**仍无法保证对所有文件做到 100% 语义等价**。

**建议：**

- 编辑前先备份文件，或使用 Git 管理
- 保存后用 `git diff` 检查输出是否符合预期
- 如果发现语义丢失、格式错乱、字段错位等问题，请提交 Issue

## 已知限制

- 不支持 SLK 中的公式、样式等非数据字段的编辑
- 行列操作以第一列值为行标识，第一列重复时可能匹配不精确
- 列宽、行高固定，不支持自适应
